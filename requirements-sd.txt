# Pourquoi un second venv. Le venv `ddpm` tourne sur diffusers 0.40, qui exige
# transformers >= 4.48 et huggingface_hub >= 1.23. ImageReward 1.5 embarque une
# copie du BERT de BLIP ecrite contre l'API transformers 4.x : elle importe
# `apply_chunking_to_forward` depuis `transformers.modeling_utils` et lit
# `tokenizer.additional_special_tokens_ids`, deux choses supprimees en
# transformers 5. Les deux contraintes sont inconciliables dans un seul env, et
# les resultats CIFAR / CelebA sont deja produits sur le stack `ddpm` gele.
#
# Cree avec --system-site-packages : torch vient de l'image Onyxia (2.14.0+cu130).
# Voir scripts/setup_sd_env.sh, qui applique aussi deux correctifs manuels.
#
# Versions installees le 19/09/2026, Python 3.13, Tesla T4.
